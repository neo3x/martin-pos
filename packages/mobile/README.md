# Martin POS Mobile

Aplicación móvil de Martin POS construida con React Native y Expo.

## Características

- Escaneo de códigos de barras y QR
- Gestión de ventas móvil
- Dashboard en tiempo real
- Sincronización con backend

## Instalación

```bash
pnpm install
```

## Desarrollo

```bash
# Iniciar Expo
pnpm start

# Android
pnpm android

# iOS
pnpm ios
```

## Build

```bash
# Android
pnpm build:android

# iOS
pnpm build:ios
```
